# Reporting a security issue

Use **Report a vulnerability** on the GitHub repository’s **Advisories** page to contact the maintainers privately. If the button is unavailable, open an issue that asks for a private reporting channel and reserve the details for that channel. [GitHub’s private reporting guide](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately)

Include the affected FluidKit commit or version, the relevant package or Studio page, and the impact you observed. A minimal example using synthetic workspace data helps maintainers investigate. Remove credentials, personal information, and original provider or customer records from attachments.
