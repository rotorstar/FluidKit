# Begriffe

| Begriff | Bedeutung im Studio |
|---|---|
| Workspace | der untersuchte lokale Modulbestand |
| Modul-ID | stabile Kennung desselben Inhalts in jeder Ansicht |
| State | bestätigter fachlicher Zustand, zum Beispiel Tabelle oder Detail |
| Revision | fortlaufender Stand einer fachlichen Änderung |
| GPU-Surface | sichtbare gezeichnete Runtime-Oberfläche |
| WebGPU | bevorzugte Browser-Grafikschnittstelle |
| WebGL2-Fallback | ausdrücklich angezeigter Ersatzpfad bei erlaubter Konfiguration |
| Effekt/Rezept | Darstellung des Weges zwischen zwei Zuständen |
| Seed | Ausgangswert für reproduzierbare Zufallsauswahl |
| Case | ein abgegrenzter Praxisfall |
| Rehearsal | kontrollierte Probe einer Bediengeschichte |
| Beat | ein erklärter Schritt dieser Geschichte |
| Frame | eine bestimmte gerenderte Bildaufnahme |
| Referenz/Kandidat | die beiden ausgewählten Bilder im Vergleich |
| Part | benannter Bestandteil einer Komponente |
| Trace | nachvollziehbare Ereignisspur |
| Guard | Regel, die einen Vorgang erlauben oder abweisen kann |
| Quote | zeitlich begrenztes Angebot im Reisefall |
| Usage | vom Modellanbieter gemeldeter Tokenverbrauch |
| Reservierung | vorsorglich zurückgehaltenes lokales Kostenbudget |
| AC | überprüfbares Akzeptanzkriterium |
| Offen/inconclusive | für eine endgültige Aussage fehlen Nachweise |
| OKF | portables Markdown-Format dieser Knowledge |

Begriffe beziehen sich auf den dokumentierten Alpha-Stand. „Bestätigt“ in einer
AI-Bewertung bedeutet eine fachliche Bewertung der Beobachtung, keine automatische
Änderung und keine vollständige Produktfreigabe.[^product]

[^product]: Produktstand, tatsächliche Aufnahmerouten und Einschränkungen im Fakten-/Bildregister.
